# Weather App 🌤️

Aplicación de clima construida con **JavaScript puro**, HTML y CSS. Consulta el clima actual de cualquier ciudad usando una API de clima.

**Live Demo:** [https://app-clima-javascript-v.netlify.app/](https://app-clima-javascript-v.netlify.app/)

## Características

- Búsqueda de clima por ciudad
- Visualización de temperatura, descripción y más datos
- Interfaz limpia y responsive
- Consumo de API externa

## Tecnologías

- JavaScript (Vanilla)
- HTML5
- CSS3
- Netlify (deploy)

## Cómo ejecutarlo localmente

1. Clona el repositorio:
```bash
git clone https://github.com/victormarkno/app-clima-javascript.git
cd app-clima-javascript
```

2. Abre `index.html` en tu navegador o usa un servidor local:
```bash
npx serve .
```
